导出范围

导出文件内含 accessToken / refreshToken，等同账号钥匙：妥善保管，别外发、别截图分享。

脱敏清单不能用于登录，只能用来看。

含凭据导出会下载含 token 的文件；脱敏导出删掉 accessToken / refreshToken 两个键。

预览不写盘；确认写入前会自动逐字节备份 plugin-auth.json。

导入规则

接受四种形态：本插件的导出信封（format: workbuddy-accounts）、裸账号数组、单个账号对象、 桌面端凭据 {"auth":{…},"account":{…}}。规则由后端执行，这里只转述： 只同步国内版（intl 账号一律拒绝）；智能合并 —— uid 已存在且现有 token 未过期则跳过，现有已过期且导入的更新则覆盖 access/refresh/expires，导入项没有 refreshToken 而现有有则跳过。 导入不会删除任何现有账号，也不会动其他供应商的条目。

启动守护进程

浏览器无法拉起本机进程。magpie 开启本插件时会自动拉起守护进程；如需手动启动， 在插件目录的终端里执行： 

node daemon.mjs
# 或 bun daemon.mjs
# 可选：--port 4390 --addr 127.0.0.1 --cfg <magpie 配置目录> --state <状态目录>

启动后打开 http://127.0.0.1:4390/（端口被占用会自动顺延）； 实际端口与绑定地址写在 <状态目录>/daemon.json。看板无鉴权， 默认只绑回环地址。
